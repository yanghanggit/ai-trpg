# 灰炉墓园（临时剧本）

> 状态：临时内容，只服务行动、记忆、物品、密室与通关链路的验证，不是最终剧情，也不是长期内容模板；正式内容接入后随 seed 一起删除。
>
> 场景图、角色与物品数值、能力声明以同目录 `crow-bell.ts` 为准，本文只写它表达不出来的东西：剧情意图、验收口径与删除条件。

内容版本 `crow-bell.v1`，`contentKey` 为 `crow-bell`。这是「黑暗奇幻」战役下的第二个剧本，与「枯钟修道院」共用战役设定、全局规则与世界职能 agent；知识库与检索评测集独立绑定。

## 背景

灰炉墓园在河谷北面的坡上，是灰炉铸钟场的旧坟地。铸钟场替河谷的村镇铸钟：报时、报丧、驱赶瘟疫。铸钟要用骨灰、黏土和蜡，瘟疫之后骨头多得没人埋，铸钟场便拿小钟换死者，把一车一车骨头烧成灰。铸坏的钟不会被重铸，匠人把它们推进废井，再用石板和灰泥封上。

钟父卡兰是铸钟场最后的守钟人，也是鸦猎们的老铸钟匠。黑疖病那年，他的妻子和女儿死在铸钟场西边的石屋里；他把她们的骨灰掺进第一口安魂钟的钟模。钟在试响时裂了，他把它沉进废井；第二口钟挂上钟楼，却再没响过。他也没有再离开墓园。如今他疯了，听见铃声就摇铃，看见活人就挥锤；他不认得旧日的搭档，也不认得误入坟地的拾骨人。

## 角色与认知边界

三个 actor 都在灰炉墓园开局，彼此不知道对方知道什么：

- **钟父卡兰（A）**：疯狂的守钟人。他记得钟楼和钟井的位置，也记得自己锁过钟楼、封过钟井；但他不认得眼前的任何活人。妻子和女儿不在新坟里，而在石壁后的废井里——这是他的秘密，也是钟井的真相。半枚铜铃、或女儿的名字，能让他迟疑一瞬，但不会让他停手。
- **鸦猎薇拉（B）**：专门收拾疯猎人的鸦猎。她认得卡兰，知道他的本名、旧日和家人；她的名单上还有他的名字。她带着另外半枚铜铃，不是为杀他，是为在最后一刻让他认出自己。她不认识拾骨人伊莱，只把他当成墓园里多出来的变量。
- **拾骨人伊莱（C）**：玩家角色。替铸钟场收骨头的河谷人，翻过塌墙进旧坟地只想装满袋子。他不认识卡兰，也不认识薇拉；他唯一多出来的一点底气，是脖子后面那块没要命的黑疖病旧疤。

`signatureNames` 只声明薇拉记得卡兰叫“卡兰”。卡兰疯了，不认人，所以没有他对薇拉的称呼；伊莱谁都不认识，所以没有他的开局称呼。名字的其余部分只能靠自我介绍、旁人的话、鸦猎名单上的半个字，或墓园里的遗物获得。

## 场景图与两条路线

| 场景 | 作用 | 关键锚点 |
| --- | --- | --- |
| 灰炉墓园 | 三方相遇与 boss 战；两条路线的起点 | 木门、空钟架、裂钟、新坟 |
| 钟楼 | 普通 stage；钟父用钥匙锁住的出口 | 安魂钟、钟绳 |
| 钟井 | 密室；借用「钟窖」的开门机制 | 裂钟、井壁名字 |

两条路线互不相干：

- **钟楼路线（钥匙）**：钟楼钥匙在卡兰背包里、不在穿戴槽，活着时也能被偷，死后留在尸体背包里靠 `steal` 搜刮。玩家在墓园对 `木门` 锚点使用钥匙，`use` 只写场景事件；灰炉墓园的小 GM 据此调用 `open_passage` 打开通往钟楼的边。玩家移动到钟楼，钟楼的小 GM 看到活物，向 world 报告「有人走出了墓园」，由 world 裁决收尾。
- **钟井路线（密室）**：断钟舌卡在中庭的裂钟里，`pickup` 可取。玩家在墓园对 `空钟架` 锚点使用断钟舌，`use` 只写场景事件；灰炉墓园的小 GM 据此调用 `open_passage` 打开通往钟井的边。玩家移动到钟井，钟井的小 GM 看到源头露了出来，向 world 报告。world 只在「钟井被打开」时收尾，这是第三种结局。

钟楼与钟井的入口都只声明 `sealed`：演员任何时候都看不见它们，木门与空钟架各自的小 GM 打开之后才以 `#编号` 出现在可去方向里——发现就是开门，两者不分离，因此不需要额外的可见性状态。卡兰开局即「去过」钟楼与钟井（`visitedStages`），所以他的方向里会出现「记得封着：钟楼 / 钟井」，名字可用，但 `move` 仍然走不进去；薇拉与伊莱没有这份记忆。

## 设计意图

这张图与这三个角色是用来压测下面几件事的，其余细节会随内容变化：

- **三方信息不对称**：B 认识 A，A 不认识 B/C，C 不认识 A/B。三个人在同一场景里，各自的开局简报与 `signatureNames` 只给出自己那一份认知；谁能叫出谁的名字，取决于内容声明与游戏中的告知，不取决于“玩家应该知道”。
- **同一张图里的两条封闭边**：墓园到钟楼、墓园到钟井各是一条初始封闭的单向边，开锁/挂钟舌之后才能通过；两条反向边从开局就通。场景图刻意保持小，只验证「钥匙开门」与「机关开密室」两条链路。
- **Boss 战的软触发**：卡兰的攻击、追击与对铃声的迟疑都写在 profile / openingBriefing 里，由模型判断，不做确定性断言。半枚铜铃的「旧日的铃声」是推理词缀：它只追加可见后果，不硬改卡兰的行动。
- **效果靠声明而非分支**：钥匙与断钟舌都只有静态见证词缀，开门由场景小 GM 依据「仅当此时」的规则裁决；玩家武器上的「别住关节」「鸦羽错步」是推理词缀，让旁人的出手有叙事上的空当，但不新增引擎分支。
- **死亡链路端到端**：玩家死亡只通知 world，收尾与结局标签仍要走 world 回合；尸体是合法目标，钥匙、半枚铜铃与名单留在尸体背包里，靠 `steal` 搜刮。

## 触发规则（写进内容，不写反例）

- 灰炉墓园：「对木门使用钟楼钥匙即开锁；仅当此时，必须打开通往钟楼的通道。对空钟架使用断钟舌即挂上钟舌；仅当此时，必须让空钟架后的石壁裂开、打开通往钟井的通道。」
- 钟楼：「报告以「同场景角色」里至少有一个活物为前提；前提成立时，才算有人登上了钟楼、封锁已被打破，必须向世界报告这条事实，并说明故事可以在这里收束。前提不成立时，本回合什么都不报告。」
- 钟井：「报告以「同场景角色」里至少有一个活物为前提；前提成立时，才算井已打开、井底的东西见了光，必须向世界报告这条事实，由世界裁决是否收束。前提不成立时，本回合什么都不报告。」
- world：「三种收尾都只由你在收到相应报告后裁定；除此之外，不要替故事收尾。」

一步一条，语义唯一，不列反例。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始世界 | 建局 | 三个 actor 全部在灰炉墓园；伊莱是唯一默认玩家；钟楼与钟井为空 |
| 通道封闭 | `player-move` 到钟楼 / 钟井 | 边存在但未开启，移动被拒；打开后才出现在可去场景 |
| 打开钟楼 | 灰炉墓园 stage 回合 | 依据钥匙事件调用 `open_passage`；边可通行并写 `passage_change` 与 stage 记忆，不写 world |
| 打开钟井 | 灰炉墓园 stage 回合 | 依据断钟舌事件调用 `open_passage`；边可通行并写 `passage_change` 与 stage 记忆，不写 world |
| 通道拒绝 / 幂等 | 无 `open_passage` 能力或无未开启边 | 整份计划被拒，场景图不变；对已开启的边再次提交也被拒 |
| 走出墓园 | 钟楼 stage 回合 | 报告进 world memory，world 据此裁决是否 `end_game` |
| 钟井收束 | 钟井 stage 回合 | 报告进 world memory；world 只在「钟井被打开」时收尾，写 `game_completed` |
| 玩家移动 | `player-move` | 只能沿连接移动；事件写入公共消息与环境记忆 |
| 默认玩家死亡 | 伊莱 HP 归零 | 只写 `death` 公共事件与 world memory，不写 `game_completed`；`status` 保持 `active`，收尾留给 world 回合 |
| 三方认知 | 开局 / 自我介绍 / 偷听 | 薇拉叫得出“卡兰”；卡兰不认人；伊莱谁都不认识；名字只能靠世界内的告知获得 |
| 钥匙归属 | `steal` / 尸体 `steal` | 钥匙不在穿戴槽，活着也能偷；死后留在尸体背包，不掉成材料 |
| 半枚铜铃 | `use` + 角色目标 | 静态见证铃声；推理词缀追加「一瞬迟疑」，不硬改卡兰的行动 |
| 尸体掉落 | 死亡阶段第三步 | 只产 `material` 并写进尸体背包；同名材料合并；钥匙、铃、名单留在背包里靠 `steal` 搜刮 |
| 普通攻击 Boss | `strike` | 钟父 block 高、血厚；正面硬拼要付代价，薇拉的钩刃与伊莱的钩子更有效，铃声能创造空当，或干脆不打 |
| stage 记忆 / 环境 | 私密沟通、移动、stage 回合 | 起点与终点 stage 都写 memory；environment 只描述当前可见状态 |
| 环境的场景名 | stage 提交 `environment` / 锚点文本 | 只能点名当前场景与开着的邻居；写未通通道对面的场景名会被拒绝，不给提前泄漏 |
| 封着出口的记性 | `visitedStages` 里去过、但现在 `sealed` 的邻站 | 只对卡兰渲染成「记得封着：钟楼 / 钟井」；不是可移动目标，`move` 仍被拒；薇拉与伊莱看不到 |

## 暂不验证

- 武器槽切换、耐久与消耗；`count` 尚未自动扣除。
- 卡兰的硬性仇恨、铃声的确定性眩晕、薇拉是否会主动与伊莱结盟；当前都靠 profile、openingBriefing 与 LLM 判断，是软触发。
- 「已发现但未通行」的独立状态（例如看见了空钟架却还没挂钟舌）：当前发现即开门，不拆成两步。
- 通用物品数量、堆叠、唯一实例与所有权历史；钟井里的骨灰与木铃只作叙事与检索对象。
- HTTP 业务接口与 Web 游戏界面。
