# 鸦葬岗（临时剧本）

> 状态：临时内容，只服务行动、记忆、道具、密室与通关链路的验证；正式内容接入后随 `crow-grave.ts` 一起删除。
>
> 舞台图、角色与道具数值、能力声明以同目录 `crow-grave.ts` 为准；本文只写剧情意图、验收口径与删除条件。

内容版本 `crow-grave.v3`，`contentKey` 为 `crow-grave`。这是「黑暗奇幻」战役下的第二个剧本，与另一剧本共用战役设定、全局规则与世界职能 agent；知识库与检索评测集独立绑定。黑疖病是战役层共享的瘟疫，不随剧本改变。

## 背景

鸦葬岗在灰墙镇北面的坡上，是黑疖病最盛时留下的乱葬岗。镇上雇收尸人把死者拖上坡，推进石窖，用锁石和铁钉封死；瘟疫之后只剩收尸人的尸车、石灰和乌鸦。

收尸人卡尔是鸦葬岗最后的收尸人。瘟疫那年，他的妻子和女儿也死了；他把她们放进封尸窖，和最早病死的人埋在一起，封窖后再没离开。如今他疯了，看见有人靠近新坟、锁石或塔门就挥锤，不认得旧日搭档，也不认得误入坟地的拾骨人。

## 角色与认知边界

- **收尸人卡尔**：疯狂的收尸人。他记得守夜塔与封尸窖的位置，也记得自己锁过塔门、封过尸窖；妻子和女儿在石壁后的封尸窖里，这是他的秘密。旧骨哨或女儿的名字能让他迟疑一瞬，但不会让他停手。
- **鸦猎薇拉**：专门收拾疯猎人的鸦猎。她认得卡尔，知道他的本名、旧日与家人；名单上还有他的名字。她带着卡尔刻的骨哨，不是为杀他，是为在最后一刻让他认出自己。她开局伏在坡上的乱坟之间（`concealed`），卡尔与伊莱都看不见她；她把伊莱当成墓园里多出来的变量。
- **拾骨人伊莱**：玩家角色。替骨炭窑收骨头的河谷人，翻过塌墙进旧坟地只想装满袋子；他不认识卡尔，也不认识薇拉。脖子后的黑疖病旧疤是他多出来的一点底气。

`signatureNames` 只声明薇拉记得卡尔叫“卡尔”。卡尔疯了不认人，伊莱谁都不认识；其余名字只能靠自我介绍、旁人的话、鸦猎名单或墓园里的遗物获得。

## 舞台与两条路线

- **鸦葬岗**：三方相遇（薇拉开局隐匿）与 Boss 战，两条路线的起点；锚点塔门、锁石、尸车、新坟。
- **守夜塔**：钥匙路线终点；锚点火盆、火绳。
- **封尸窖**：密室路线终点；锚点小棺、石壁名字。

- **守夜塔路线**：塔门钥匙在卡尔背包里，活着可偷，死后靠 `loot` 搜刮。对塔门锚点使用钥匙只写舞台事件；鸦葬岗据此 `open_passage`，走到守夜塔后由守夜塔向 world 报告「有人登塔、点起烽火」。
- **封尸窖路线**：窖钉卡在尸车里，`pickup` 可取。对锁石锚点使用窖钉只写舞台事件；鸦葬岗据此打开石壁，走到封尸窖后由封尸窖向 world 报告「窖底见光」。封尸窖被打开是第三种收尾，由 world 裁决。

两条路线互不相干。两处入口都只声明 `sealed`，由鸦葬岗打开后才以 `#编号` 出现在可去方向里——发现即开门，不另建可见性状态。卡尔开局即「去过」守夜塔与封尸窖，所以只有他的方向里会出现「记得封着」；薇拉与伊莱没有这份记忆。

## 设计意图

- **三方信息不对称**：B 认识 A，A 不认识 B/C，C 不认识 A/B；各自的开局简报与 `signatureNames` 只给自己的那一份认知。
- **两条封闭边**：同一张图里放两条初始 `sealed` 的单向边，分别验证「钥匙开门」与「机关开密室」，反向边开局就通。卡尔的攻击与迟疑都靠 profile / openingBriefing 软触发，不做确定性断言。
- **携带者动作与声明**：封尸锤提供单体挥击与横扫（`maxTargets: 2`），两把刃器只提供单体挥击；钥匙与窖钉只有静态见证词缀，开门由舞台依据「仅当此时」裁决，武器上的「别住关节」「错步」只追加叙事空当。
- **隐匿 demo**：薇拉开局隐匿；移动、传送、等待、换装与查看不破隐，说话、攻击、递物等交互动作会先自动现身。隐匿者不进名单与被动观察；舞台仍全知，但提示词把隐匿者隔离在 environment 之外。
- **死亡链路**：玩家死亡只通知 world；尸体是合法目标，钥匙、骨哨与名单留在尸体背包里，靠 `loot` 搜刮。

## 触发规则（写进内容，不写反例）

- 鸦葬岗：「对塔门使用塔门钥匙即开锁；仅当此时，必须打开通往守夜塔的通道。对锁石使用窖钉即打开锁石；仅当此时，必须让石壁裂开、打开通往封尸窖的通道。」
- 守夜塔：「同舞台角色里至少有一个活物时，才算有人登塔、点起烽火；仅当此时，必须向世界报告，并说明故事可以收束。」
- 封尸窖：「同舞台角色里至少有一个活物时，才算窖底见了光；仅当此时，必须向世界报告，由世界裁决是否收束。」
- world：「三种收尾只由你在收到相应事实后裁决；除此之外，不要替故事收尾。」

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始世界 | 建局 | 三个 actor 全在鸦葬岗，薇拉开局隐匿；伊莱是唯一默认玩家；守夜塔与封尸窖为空 |
| 通道生命周期 | `player-move` / `open_passage` / 重复提交 | 边存在但未开启时移动被拒；打开后通行并写 `passage_change` 与 stage 记忆，不写 world；无能力或重复提交整份计划被拒 |
| 两条路线收尾 | 守夜塔 / 封尸窖 stage 回合 / world | 报告进 world memory；world 据报告裁决三种收尾（逃出 / 死亡 / 封尸窖打开），写 `game_completed` 与它自己命名的 outcome |
| 玩家移动与死亡 | `player-move` / 伊莱 HP 归零 | 只能沿连接移动，事件写入公共事件与环境记忆；死亡只写 `death` 与 world memory，`status` 保持 `active` |
| 三方认知 | 开局 / 自我介绍 / 偷听 | 薇拉叫得出“卡尔”；卡尔与伊莱只看得见彼此，名单里没有薇拉；其余名字只能靠世界内告知获得 |
| 钥匙与妙手 | 活人 `steal` / 尸体 `loot` / `inspect` / `fit` | 钥匙不在穿戴槽，活着也能偷，死后留在背包；名字要靠 `inspect` 看清（占一次行动）；伊莱比卡尔敏捷，偷钥匙不留痕；薇拉更快，偷不到她的东西；没有妙手的人拿钥匙也开不了门 |
| 对上机关 | `fit` + `itemName` + `targetAnchor` | 塔门钥匙开塔门、窖钉开锁石，各自声明 `affixes.fit`；只写舞台事件，开门由鸦葬岗下一轮裁决 |
| 旧骨哨 | `use` + 角色目标 | 静态见证哨声；推理词缀追加「一瞬迟疑」，不硬改卡尔的行动 |
| 尸体掉落 | 死亡阶段第三步 | 只产 `material` 并写进尸体背包；同名合并；钥匙、骨哨、名单留在背包里靠 `loot` 搜刮 |
| Boss 战 | `strike` / `cleave` | 卡尔血厚格挡高；正面硬拼要付代价，哨声能创造空当；横扫最多 2 个目标，超过或重复目标整份计划被拒，换掉武器后 `cleave` 消失 |
| 位置与记忆 | stage 回合 / `visitedStages` | 起点与终点 stage 都写 memory；environment 只写当前可见、不点名未通舞台；只有卡尔记得封着的出口 |
| 隐匿与现身 | 薇拉移动 / 说话 / 查看 / `hide` / `reveal` | 移动与查看不破隐；说话等交互自动现身并写一次反馈；隐匿者不进名单；被察觉的隐匿查看只给目标匿名提示；舞台提示词隔离隐匿者 |

## 暂不验证

武器槽切换、耐久与消耗、道具数量与所有权历史、「已发现但未通行」的独立状态、卡尔的硬性仇恨与骨哨眩晕、薇拉是否会与伊莱结盟、HTTP 业务接口与 Web 游戏界面。当前这些要么靠 profile 与 LLM 判断，要么尚未建模。
