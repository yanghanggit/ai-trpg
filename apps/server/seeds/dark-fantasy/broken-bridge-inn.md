# 断桥客栈（临时测试剧本）

> 状态：临时内容，只服务对话与外观通知的验证；这些测试稳定或正式内容接入后，随 `broken-bridge-inn.ts` 一起删除。
>
> 舞台图、角色与能力声明以同目录 `broken-bridge-inn.ts` 为准；本文只写场景意图、验收口径与删除条件。

内容版本 `broken-bridge-inn.v2`，`contentKey` 为 `broken-bridge-inn`。这是「黑暗奇幻」战役下的第三个剧本，与另外两个剧本共用战役设定、全局规则与世界职能 agent；知识库与检索评测集独立绑定。它只有一个舞台，不承担通道、机关、移动、战斗与通关链路的验证。

## 场景

断桥客栈开在河谷旧桥的北头。桥断了很多年，过河要绕两天山路；一场秋末的雨把最后三个走不动的人困在同一间炉厅里。

- **温娜**：客栈掌柜。黑疖病带走了她的丈夫和帮工，她一个人把客栈撑到现在。她供炉火、收房钱、不许人上楼，也从不提桥是怎么断的。
- **戈特**：贩盐的货郎。骡子和货留在南岸，他被雨困在北岸三天；嘴上是天气与行情，心里算的是怎么把最后一点盐卖出去。
- **无名旅人**：玩家角色。天黑后进门，斗篷还在滴水；他要天亮前过河去灰墙镇等一个约好的人，但不想让人知道那个人是谁。

三个人开局都在炉厅，彼此可见，都能开口。没有通道、机关与武器；除玩家随身的几件衣物与饰品外没有可拾取的道具。故事的全部尺度就是这一间屋子和这一夜。

## 角色与认知边界

- 温娜与戈特认识彼此：温娜叫他“戈特”，戈特叫她“温掌柜”。
- 两人都不知道旅人的真名，只把他认作“披斗篷的”；旅人也不知道他们的真名，只认作“掌柜的”和“盐贩子”。
- 名字只来自开局关系与屋内的自我介绍；真名、桥断的真正原因、戈特的货与旅人在等谁，都只能靠对话浮出来。

## 设计意图

- **单房间**：舞台只有一个，连接为空；测试时不必先找路、开门或处理跨舞台状态。
- **三种对话**：三个人都声明 `say` / `whisper` / `announce`，可以点对点说话、只让一个人听见，或向全屋宣告；`wait` 用来让对话停在原地，`brawl` 只作被逼到墙角时的退路。
- **不对称称呼**：每个角色对另外两人各有一套称呼，验证“名字就是地址”与观察者视角；真名不因同处一室自动可知。
- **软触发**：温娜护着柜台与楼上，戈特想套话与卖盐，旅人藏着等人的目的；这些都写在 profile 与开局简报里，由角色自己判断，不做确定性断言。
- **换装与外观通知**：旅人开局穿着湿透的旧斗篷、绕着灰羊毛围巾，行李里还有一件干羊毛斗篷和一枚贴身的骨符。护甲与围巾参与外观，换上去或换下来都会重算外观并广播；骨符声明不参与外观，换上去或换下来都不产生外观变化，也没有任何通知。另外两人没有可换的衣物，只作为旁观的接收方。
- **收尾只有两种**：屋里的人全部睡下，或有人推门走进雨里。两种都只由 world 在收到舞台报告后裁决；舞台只负责报告事实。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 开局布局 | 建局 | 只有一个舞台“炉厅”，三个 actor 全在场，旅人是唯一默认玩家；没有连接 |
| 公开对话 | `say` / `announce` | 目标与同舞台其他人都能听见；事件写入舞台记忆与在场者观察 |
| 私下对话 | `whisper` | 只有目标听见；第三人不获得内容 |
| 称呼与真名 | 开场 / 自我介绍 | 温娜与戈特互称“戈特”“温掌柜”；旅人被认作“披斗篷的”；真名只能靠世界内告知 |
| 对话审核 | 玩家 `say` / `whisper` / `announce` | 现代词与出界台词被拒绝且不落库；符合中世纪瘟疫语汇的黑暗内容放行 |
| 记忆连续性 | 多轮对话 | 角色记得自己听过的话、谁对自己说过什么，以及自己给谁认下了什么称呼 |
| 舞台收尾 | 有人离开 / 全部睡下 | 舞台向 world 报告事实；world 只在收到报告后裁决收尾 |
| 换装改外观 | `equip` / `unequip` 护甲或围巾 | 外观重算并写回；当事人与同舞台的另外两人各收到一条外观变化 |
| 无声换装 | `equip` / `unequip` 贴身的骨符 | 不重算外观、不广播；旁人只看到原来的样子 |
| 同槽替换 | 湿透的旧斗篷 ↔ 干羊毛斗篷 | 旧件回背包，新件上身；外观变化来自新旧两件共同判定 |

## 暂不验证

移动、通道、机关、战斗平衡、道具拾取与偷窃、隐匿、跨舞台传音、RAG 检索质量。这些由另外两个剧本或单独测试覆盖；断桥客栈不提供对应能力。
