# 枯钟修道院（临时剧本）

> 状态：临时内容，只服务行动、记忆、道具与通关链路的验证，不是最终剧情，也不是长期内容模板；正式内容接入后随 seed 一起删除。
>
> 舞台图、角色与道具数值、能力声明以同目录 `bell-monastery.ts` 为准，本文只写它表达不出来的东西：剧情意图、验收口径与删除条件。

内容版本 `bell-monastery.v17`，`contentKey` 为 `bell-monastery`。测试世界使用独立的小型 `TEST_WORLD`，不随本剧本变化。

## 背景

「黑疖病」扫过河谷：先死牲口，再死人，腋下与脖颈鼓起黑硬的疖子。修道院收留过病人，也烧过尸体；院长发现唱诗班一个接一个倒下后，封死北面铁闸门，带人从别的路离开。钟楼再没响过。

留下的是掘墓人奥德里克、他的狗与地窖鼠群。鼠王靠尸体活下来，身上的跳蚤、啃过的粮食、钻过的裹尸布都是瘟疫的一部分。玩家扮演的无名者被封进刻满符文的棺材，架在乱葬坑沿醒来——瘟疫死者从不用棺材下葬。

## 剧情路径

**谈判路线**：玩家推开棺盖爬进墓园，与奥德里克沟通。铁闸门的钟形纹下刻着旧铭文「灰烬之下，旧钟无名」；有人对他说出这句，他会当成留下守钟的故人，可能在下一次 NPC 回合 `give` 交出钥匙——软触发，由模型判断，不是硬性服从。玩家走到铁闸门、对锁孔使用钥匙：`use` 只写舞台事件，由铁闸门这座舞台调用 `open_passage` 打开山道；玩家移动到山道，山道这座舞台向 world 报告「有人逃出」，由 world 裁决是否结束。

**暴力路线**：玩家攻击奥德里克，小狗“煤渣”通过同舞台战斗记忆在下一次 NPC 回合自主反击；小鼠“坏运气”看到冲突后跑回地窖报信。鼠王是否苏醒由 openingBriefing 与 LLM 判断，不通过系统状态移除。钥匙在奥德里克背包里、不在穿戴槽，因此活着时也能被偷。

**Boss 路线**：鼠王被本舞台的非 `wait` 行为惊醒后追杀所有非鼠类活物，无目标时按舞台图自行搜索；攻击力足以秒杀普通角色。普通武器打不穿鼠王；火把需先装备到 `weapon` 槽，并声明 `strike` 动作，角色才能挥击。

**钟窖路线**：鼠王身边收着一截黄铜钟舌（`valuable` + `event`，不是身体材料），活着偷不到（无名者比鼠王慢，`steal` 会失手），得把它打死再用 `loot` 取；`steal` 只是敏捷够高时的备选路径，不是这条路线的前提。玩家在地窖对 `祭坛` 锚点使用钟舌（`use` 只写舞台事件），地窖这座舞台据此调用 `open_passage` 打开后墙的通道；玩家移动到钟窖，钟窖这座舞台看到源头露了出来，向 world 报告。world 只在「钟窖被打开」时收尾，这是第三种结局；钟舌在鼠王身上，拿到它是必由之路。

鼠王开局即「去过」钟窖（`visitedStages`，鼠群是从那里钻出来的）：到访是记忆，所以它的 plan 输入里会出现「记得封着：钟窖」，名字可用，但 `move` 仍然走不进去；其余角色没有这份记忆，钟窖对它们连「封着的出口」都不是。

两条通关路线互不相干：钥匙管铁闸门（出走），钟舌管钟窖（断源）。钟窖入口只声明 `sealed`：角色任何时候都看不见它，地窖这座舞台打开之后才以 `#编号` 出现在可去方向里——发现就是开门，两者不分离，因此不需要额外的可见性状态。

## 设计意图

这张图与这几个角色是用来压测四件事的，其余细节会随内容变化：

- **同一张图里共存三类边**：从棺材到山道只有一条路径（棺材 → 墓园 → 铁闸门 → 开门 → 山道），双向、单向出口与初始封闭的单向边各出现一次；地窖与焚尸房只能原路返回，山道无路可去。地窖到钟窖是第二条初始封闭的单向边，专用来验证「密室」：角色看不到它，地窖这座舞台看得到并能打开。
- **效果靠声明而非分支**：火把的词缀不写「鼠」，命中由 affix agent 依据种族与外观判断，所以「普通攻击打不动、火把打得动」是内容 + 结算的结果，不是代码里的特判。
- **软触发优先**：暗语只进 `say` 的记忆、由奥德里克自己决定 `give`；鼠王沉睡写在 openingBriefing、不写状态机；祭坛开门、钟窖报告、世界收尾都由各自的 agent 判断。它们不做确定性断言，所以**触发条件必须在内容里写成一条规则，而不是一串禁令**：`仅当 <引擎动作> 时（= <故事动作>），必须 <后果>`。地窖是「对祭坛使用钟舌即开锁；仅当此时，必须打开通道」，钟窖是「本回合场上有活物即洞已打开；仅当此时，必须报告世界」，山道是「活物出现在山道上即封锁已被打破；仅当此时，必须报告世界」，世界是「仅当钟窖被打开、源头见光时，这一轮只裁决故事结束」。一步一条，语义唯一，不列反例。
- **死亡链路端到端**：主角死亡只通知 world，收尾与结局标签仍要走 world 回合；尸体是合法目标，因此掉落要落在尸体背包、靠 `loot` 搜刮。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始世界 | 建局 | 玩家出生在棺材；墓园三 actor、棺材与地窖各一；焚尸房墙角挂着松脂火把；铁闸门与山道为空 |
| 通道封闭 | `player-move` 到山道 | 边存在但未开启，移动被拒；打开后才出现在可去舞台 |
| 打开通道 | 铁闸门 stage 回合 | 依据钥匙事件调用 `open_passage`；边可通行并写 `passage_change` 与 stage 记忆，不写 world |
| 通道拒绝 / 幂等 | 无 `open_passage` 能力或无未开启边 | 整份计划被拒，舞台图不变；对已开启的边再次提交也被拒 |
| 逃出后报告 | 山道 stage 回合 | 报告进 world memory，world 据此裁决是否 `end_game` |
| 玩家移动 | `player-move` | 只能沿连接移动；事件写入公共事件与环境记忆 |
| 默认玩家死亡 | 无名者 HP 归零 | 只写 `death` 公共事件与 world memory，不写 `game_completed`；`status` 保持 `active`，收尾留给 world 回合 |
| 动物语言 | NPC 沟通动作 | 同族清晰沟通，对非同族只发本族叫声 |
| 狗的反应 | 挥击奥德里克后推进小狗“煤渣” | 小狗“煤渣”据战斗记忆与 profile 自主决定反应，不是硬触发器；犬用 `brawl`（撕咬）反击 |
| 小鼠“坏运气”报信 | 冲突后推进小鼠“坏运气” | 移动到地窖并报信；是否要两轮由计划顺序与动作上限决定 |
| 沉睡唤醒 | 舞台内说话、攻击或非 `wait` | 由鼠王 openingBriefing 与 LLM 判断，不做确定性断言 |
| 查看 / 窃取 / 对合 / 搜刮 / 给予 | 无名者的「妙手」带 `inspect` + `steal` + `fit`；`loot` 与暗语触发的 `give` 两个人类都会 | 查看与搜刮各占一次行动；窃取为 private；钥匙不在穿戴槽，活着也能偷；无名者与奥德里克敏捷相同，偷得到但会被察觉；鼠王比无名者快，活着的钟舌偷不到；暗语通过 say 进入记忆，奥德里克自行选择 give |
| 妙手 | 无名者的技艺，带 `inspect` + `steal` + `fit` | 奥德里克不会妙手：他带着闸门钥匙却没有 `fit`，钥匙在他手里只是块铁；鼠王比无名者快，活着的钟舌偷不到 |
| 尸体掉落 | 死亡阶段第三步 | 只产 `material` 并写进尸体背包；同名材料合并；重推外观不会再次掉落；搜刮走 `loot` |
| 对合机关 | `fit` + `itemName` + `targetAnchor` | 锚点从舞台的 `锁孔` / `祭坛` 枚举中选择；钥匙与钟舌各自声明 `affixes.fit`，没有它连点名都过不了；只写舞台事件，不改连通性、不通知 world；开门由该舞台下一轮裁决 |
| 游戏结束 | world `end_game` | 只有 world 收尾，写 `game_completed` 与它自己命名的 `outcome` |
| 普通挥击 Boss | `strike` | 鼠王身上那层硬皮 block 100，只有火把的武器伤害打不穿，靠词缀由 LLM 额外放大 |
| 鼠王攻击 | 苏醒后推进鼠王 | 用 `brawl`，力量 120 一口秒杀普通角色；清场后自行搜索下一个舞台 |
| 窝中钟舌 | 尸体 `loot`；活着要 `steal`，敏捷得高于鼠王 | `valuable` + `event`，可在 `祭坛` 锚点上 `fit`；不是身体材料 |
| 钟窖收束 | 钟舌 + `祭坛` 锚点 + 地窖 `open_passage` + 钟窖 `notify_world` + world 回合 | 世界收尾为「钟窖被打开」，写 `game_completed`；这是第三种结局 |
| stage 记忆 / 环境 | 私密沟通、移动、stage 回合 | 起点与终点 stage 都写 memory；environment 只描述当前可见状态 |
| 环境的舞台名 | stage 提交 `environment` / 锚点文本 | 只能点名当前舞台与开着的邻居；写未通通道对面的舞台名会被拒绝，不给提前泄漏 |
| 封着出口的记性 | `visitedStages` 里去过、但现在 `sealed` 的邻站 | 只对该 actor 渲染成「记得封着：钟窖」；不是可移动目标，`move` 仍被拒；没去过的角色看不到 |
| 舞台道具同步 | 拾取后推进 stage | environment 不再出现该道具，也不写消失过程；锚点保留，拾取事件留在 stage memory |

## 暂不验证

- 武器槽切换、耐久与消耗；`count` 尚未自动扣除；拾取后的堆叠与其他武器效果。
- 暗语的硬性服从、沉睡 / 苏醒的确定性行为；当前都靠 profile 与 LLM 判断，是软触发。
- 「已发现但未通行」的独立状态（例如发现了暗门却还缺钥匙）：当前发现即开门，不拆成两步；真需要时再加属于边的可见性字段，不在本剧本里做。
- 通用道具数量、堆叠、唯一实例与所有权历史。
- HTTP 业务接口与 Web 游戏界面。
