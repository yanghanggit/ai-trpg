# 枯钟修道院（临时剧本）

> 状态：临时内容，只服务行动、记忆、物品与通关链路的验证，不是最终剧情，也不是长期内容模板；正式内容接入后随 seed 一起删除。
>
> 场景图、角色与物品数值、能力声明以同目录 `bell-monastery.ts` 为准，本文只写它表达不出来的东西：剧情意图、验收口径与删除条件。

内容版本 `dark-fantasy.v13`，`contentKey` 为 `bell-monastery`。测试世界使用独立的小型 `TEST_WORLD`，不随本剧本变化。

## 背景

「黑疖病」扫过河谷：先死牲口，再死人，腋下与脖颈鼓起黑硬的疖子。修道院收留过病人，也烧过尸体；院长发现唱诗班一个接一个倒下后，封死北面铁闸门，带人从别的路离开。钟楼再没响过。

留下的是掘墓人奥德里克、他的狗与地窖鼠群。鼠王靠尸体活下来，身上的跳蚤、啃过的粮食、钻过的裹尸布都是瘟疫的一部分。玩家扮演的无名者被封进刻满符文的棺材，架在乱葬坑沿醒来——瘟疫死者从不用棺材下葬。

## 剧情路径

**谈判路线**：玩家推开棺盖爬进墓园，与奥德里克沟通。铁闸门的钟形纹下刻着旧铭文「灰烬之下，旧钟无名」；有人对他说出这句，他会当成留下守钟的故人，下一轮 `give` 交出钥匙。玩家走到铁闸门、对锁孔使用钥匙：`use` 只写场景事件，由铁闸门的小 GM 调用 `open_passage` 打开山道；玩家移动到山道，山道的小 GM 向 world 报告「有人逃出」，由 world 裁决是否结束。

**暴力路线**：玩家攻击奥德里克，煤渣通过同场景战斗记忆在下一次 NPC 回合自主反击；坏运气看到冲突后跑回地窖报信。鼠王是否苏醒由 openingBriefing 与 LLM 判断，不通过系统状态移除。钥匙在奥德里克背包里、不在穿戴槽，因此活着时也能被偷。

**Boss 路线**：鼠王被本场景的非 `wait` 行为惊醒后追杀所有非鼠类活物，无目标时按场景图自行搜索；攻击力足以秒杀普通角色。普通武器打不穿鼠王；火把需先装备到 `weapon` 槽，并声明 `strike` 动作，角色才能挥击。

## 设计意图

这张图与这几个角色是用来压测四件事的，其余细节会随内容变化：

- **同一张图里共存三类边**：从棺材到山道只有一条路径（棺材 → 墓园 → 铁闸门 → 开门 → 山道），双向、单向出口与初始封闭的单向边各出现一次；地窖与焚尸房只能原路返回，山道无路可去。
- **效果靠声明而非分支**：火把的词缀不写「鼠」，命中由 affix agent 依据种族与外观判断，所以「普通攻击打不动、火把打得动」是内容 + 结算的结果，不是代码里的特判。
- **软触发优先**：暗语只进 `say` 的记忆、由奥德里克自己决定 `give`；鼠王沉睡写在 openingBriefing、不写状态机。两者都测「LLM 在角色设定内执行」，不做确定性断言。
- **死亡链路端到端**：主角死亡只通知 world，收尾与结局标签仍要走 world 回合；尸体是合法目标，因此掉落要落在尸体背包、靠 `steal` 搜刮。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始世界 | 建局 | 玩家出生在棺材；墓园三 actor、棺材与地窖各一；焚尸房有场景物品；铁闸门与山道为空 |
| 通道封闭 | `player-move` 到山道 | 边存在但未开启，移动被拒；打开后才出现在可去场景 |
| 打开通道 | 铁闸门 stage 回合 | 依据钥匙事件调用 `open_passage`；边可通行并写 `passage_change` 与 stage 记忆，不写 world |
| 通道拒绝 / 幂等 | 无 `open_passage` 能力或无未开启边 | 整份计划被拒，场景图不变；对已开启的边再次提交也被拒 |
| 逃出后报告 | 山道 stage 回合 | 报告进 world memory，world 据此裁决是否 `end_game` |
| 玩家移动 | `player-move` | 只能沿连接移动；事件写入公共消息与环境记忆 |
| 默认玩家死亡 | 无名者 HP 归零 | 写 `game_completed`，`status=completed`，后续行动被拒 |
| 动物语言 | NPC 沟通动作 | 同族清晰沟通，对非同族只发本族叫声 |
| 狗的反应 | 挥击奥德里克后推进煤渣 | 煤渣据战斗记忆与 profile 自主决定反应，不是硬触发器；犬用 `brawl`（撕咬）反击 |
| 坏运气报信 | 冲突后推进坏运气 | 移动到地窖并报信；是否要两轮由计划顺序与动作上限决定 |
| 沉睡唤醒 | 场景内说话、攻击或非 `wait` | 由鼠王 openingBriefing 与 LLM 判断，不做确定性断言 |
| 窃取 / 给予 | `steal` / 暗语触发 `give` | 窃取为 private；钥匙不在穿戴槽，活着也能偷；暗语通过 say 进入记忆，奥德里克自行选择 give |
| 尸体掉落 | 死亡阶段第三步 | 只产 `material` 并写进尸体背包；同名材料合并；重推外观不会再次掉落；搜刮走 `steal` |
| 使用钥匙 | `use` + `targetAnchor` | 锚点从场景的 `锁孔` 枚举中选择；只写场景事件，不改连通性、不通知 world；开门由铁闸门下一轮裁决 |
| 游戏结束 | world `end_game` | 只有 world 收尾，写 `game_completed` 与它自己命名的 `outcome` |
| 普通挥击 Boss | `strike` | 鼠王 block 100，只有火把的武器伤害打不穿，靠词缀由 LLM 额外放大 |
| 鼠王攻击 | 苏醒后推进鼠王 | 用 `brawl`，damage 60 秒杀普通角色；清场后自行搜索下一个场景 |
| stage 记忆 / 环境 | 私密沟通、移动、stage 回合 | 起点与终点 stage 都写 memory；environment 只描述当前可见状态 |
| 场景物品同步 | 拾取后推进 stage | environment 不再出现该物品，也不写消失过程；拾取事件留在 stage memory |

## 暂不验证

- 武器槽切换、耐久与消耗；`count` 尚未自动扣除；拾取后的堆叠与其他武器效果。
- 暗语的硬性服从、沉睡 / 苏醒的确定性行为；当前都靠 profile 与 LLM 判断，是软触发。
- 通用物品数量、堆叠、唯一实例与所有权历史。
- HTTP 业务接口与 Web 游戏界面。
