# 枯钟修道院（临时剧本）

> 状态：临时内容，只服务行动、记忆、道具与通关链路的验证；正式内容接入后随 `bell-monastery.ts` 一起删除。
>
> 舞台图、角色与道具数值、能力声明以同目录 `bell-monastery.ts` 为准；本文只写剧情意图、验收口径与删除条件。

内容版本 `bell-monastery.v17`，`contentKey` 为 `bell-monastery`。测试世界使用独立的小型 `TEST_WORLD`，不随本剧本变化。

## 背景

黑疖病扫过河谷：先死牲口，再死人。修道院收留过病人，也烧过尸体；院长发现唱诗班一个接一个倒下后，封死北面铁闸门，带人从别的路离开。钟楼再没响过。

留下的是掘墓人奥德里克、他的狗与地窖鼠群。鼠王靠尸体活下来，跳蚤、啃过的粮食、钻过的裹尸布都带着瘟疫。玩家扮演的无名者被封进刻满符文的棺材，在乱葬坑沿醒来——瘟疫死者从不用棺材下葬。

## 路线

- **谈判**：推开棺盖进入墓园，与奥德里克沟通。铁闸门的钟形纹下刻着「灰烬之下，旧钟无名」；说出这句，他可能在下一次 NPC 回合 `give` 交出钥匙——软触发，由模型判断。对锁孔使用钥匙只会写舞台事件，由铁闸门这座舞台 `open_passage`；走到山道后，山道向 world 报告「有人逃出」。
- **暴力**：攻击奥德里克后，小狗“煤渣”据同舞台战斗记忆自主反击；小鼠“坏运气”跑回地窖报信。鼠王是否苏醒由 openingBriefing 与 LLM 判断，不写状态机。钥匙在奥德里克背包、不在穿戴槽，活着也能偷。
- **Boss**：鼠王被本舞台的非 `wait` 行为惊醒后追杀所有非鼠类活物，无目标时按舞台图搜索；攻击力足以秒杀普通角色。普通武器打不穿；火把需装备到 `weapon` 槽并声明 `strike`，角色才能挥击。
- **钟窖**：鼠王带着钟舌（`valuable` + `event`，不是身体材料），活着偷不到（无名者比鼠王慢），打死后再 `loot`；`steal` 只是敏捷够高时的备选。对祭坛使用钟舌打开地窖后墙，走到钟窖后由舞台向 world 报告。钟窖被打开是第三种结局，world 据此裁决，钟舌是必经。

鼠王开局即「去过」钟窖（`visitedStages`）：到访是记忆，所以只有它的 plan 输入里会出现「记得封着：钟窖」，名字可用，但 `move` 仍走不进去；其余角色连这道封着的出口都不知道。两条通关路线互不相干，入口都只声明 `sealed`，发现即开门，不另建可见性状态。

## 设计意图

- **三类边同图**：从棺材到山道只有一条路径（棺材 → 墓园 → 铁闸门 → 开门 → 山道），双向、单向出口与初始封闭的单向边各出现一次；地窖与焚尸房只能原路返回，山道无路可去。地窖到钟窖是第二条初始封闭边，专用来验证「密室」。
- **效果靠声明**：火把词缀不写「鼠」，命中由 affix agent 依据种族与外观判断；「普通攻击打不动、火把打得动」是内容与结算的结果，不是代码特判。
- **软触发写成规则**：暗语、沉睡、开门、报告与收尾都不做确定性断言，内容只写一条 `仅当 <引擎动作> 时（= <故事动作>），必须 <后果>`：地窖是「对祭坛使用钟舌即开锁」，钟窖与山道是「场上有活物即必须报告」，world 是「仅当钟窖被打开、源头见光时裁决结束」。
- **死亡链路端到端**：主角死亡只通知 world，收尾与结局标签仍走 world 回合；尸体是合法目标，掉落落在尸体背包、靠 `loot` 搜刮。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始与地图 | 建局 | 玩家出生在棺材；墓园三 actor、棺材与地窖各一；焚尸房墙角挂着松脂火把；铁闸门与山道为空 |
| 通道生命周期 | `player-move` / `open_passage` / 重复提交 | 边存在但未开启；打开后通行并写 `passage_change` 与 stage 记忆；无能力或对已开启边再次提交时整份计划被拒 |
| 逃出与收尾 | 山道 stage 回合 / world `end_game` | 报告进 world memory；只有 world 收尾，写 `game_completed` 与它自己命名的 `outcome` |
| 移动与舞台状态 | `player-move` / stage 回合 | 只能沿连接移动；起终点 stage 写 memory；environment 只写当前可见，未通舞台名被拒 |
| 默认玩家死亡 | 无名者 HP 归零 | 只写 `death` 与 world memory，不写 `game_completed`；`status` 保持 `active`，收尾留给 world |
| NPC 软反应 | 推进狗 / 小鼠 / 鼠王 | 同族清晰沟通，非同族只发本族叫声；狗据战斗记忆反击；小鼠报信；鼠王苏醒由 briefing 与 LLM 判断，不做确定性断言 |
| 妙手与取物 | `inspect` / `steal` / `fit` / `loot` / `give` | 查看与搜刮各占一行动；窃取为 private；钥匙活着可偷；无名者与奥德里克敏捷相同，偷得到但会被察觉；鼠王更快，活钟舌偷不到；暗语经 `say` 进记忆后由奥德里克自行 `give`；没有 `fit` 的角色拿钥匙也开不了门 |
| 尸体掉落 | 死亡阶段第三步 | 只产 `material` 进尸体背包；同名合并；重推外观不再掉；搜刮走 `loot` |
| Boss 战斗 | `strike` / 火把 / 鼠王 `brawl` | 鼠王硬皮 block 100，普通武器打不穿；火把需装备并声明 `strike`；鼠王力量 120，一口秒杀普通角色，清场后自行搜索 |
| 钟窖收束 | 钟舌 + 祭坛 + 地窖 `open_passage` + 钟窖报告 + world | 世界收尾为「钟窖被打开」，写 `game_completed`；钟舌是必由之路 |
| 认知与同步 | `signatureNames` / `visitedStages` / 拾取 | 只有鼠王记得封着的钟窖；环境不泄漏未通舞台名；拾取后 stage environment 同步，锚点保留，拾取事件留在 stage memory |

## 暂不验证

- 武器槽切换、耐久与消耗；`count` 尚未自动扣除；拾取后的堆叠与其他武器效果。
- 暗语的硬性服从、沉睡 / 苏醒的确定性行为；当前都靠 profile 与 LLM 判断。
- 「已发现但未通行」的独立状态、通用道具数量与所有权历史、HTTP 业务接口与 Web 游戏界面。
