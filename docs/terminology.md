# 引擎概念用词

结论：一个概念只有一个中文词，中文词与标识符一一对应。用词是契约的一部分——它同时出现在提示词、记忆、文档与断言里，换一个词就是换一套说法。

## 四个实体

| 概念 | 中文 | 标识符 | 边界 |
| --- | --- | --- | --- |
| actor | 角色 | `actor` | 可交互的个体；NPC 与玩家是它的两种控制者，不是实体 |
| stage | 舞台 | `stage` | 角色活动的地点，承载自己的故事与环境 |
| item | 道具 | `item` | 可拿取、穿戴、使用的东西，含武器、护甲、材料 |
| world | 世界 | `world` | 其余一切与跨舞台的管理；`世界职能` 是它的职责，不是第五个实体 |

## 机制词

| 词 | 指什么 | 不用别的说法 |
| --- | --- | --- |
| 仲裁 | 舞台对本舞台的判定与计划 | 不用 `裁决`，那是世界的事 |
| 裁决 | 世界对世界级事实与收尾的判定 | 不用 `裁定`，也不用 `仲裁` |
| 公共事件 | `game_messages` 里的一行：上帝视角、带名字 | 不用 `公共消息` |
| 锚点 | 舞台上可被角色作用的位置或部位 | 不用 `交互点` |
| 战役设定 | 跨剧本不变的题材与边界（`campaignSetting`） | 不用 `世界观` |

两组分层不是同义词：`动作` 是引擎的动作种类，`行动` 是角色实际做过的事；`轮次` 是 agent loop 的迭代，`回合` 是实体的回合。

## 已废弃的说法

下表同时是检查脚本的输入：新增一行等于新增一条检查。框架层出现即视为用词不一致（检查手动跑，只报告、不阻断）；叙述里的自然用法不受约束，需要保留时在同一行写 `terms-allow: <词>`。

| 废弃 | 正名 | 说明 |
| --- | --- | --- |
| `场景` | 舞台 | 叙事里的「一幕」写故事或情节，不借用实体名 |
| `物品` | 道具 | 外延含武器、护甲与材料 |
| `演员` | 角色 | 舞台隐喻不引入第三个称呼 |
| `小 GM` | 舞台 | 舞台就是这一台的小 GM，不需要第二个名字 |
| `交互点` | 锚点 | 锚点是唯一的施加点 |
| `公共消息` | 公共事件 | 与 `公共事件流` 同源 |
| `世界观` | 战役设定 | 与 `campaignSetting` 同名 |
| `裁定` | 裁决 | 世界只做一个判定动词 |
| `scene` | `stage` | 读侧投影曾用 `scene`，已统一 |

## 新概念怎么定词

- 先查上面两张表；同义或近义都不新增第二个词。
- 词必须罩住外延：道具含装备，所以不叫消耗品；外延变了就换词，不复用旧名。
- 正名不让步：新词与旧词冲突时换新词，不把既有正名改窄。
- 中文改词时标识符同批改；数据可重灌，不写兼容层，也不迁历史局。
