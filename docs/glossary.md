# 术语表：名字与引用

同一个实体在不同观察者眼里可能被叫作不同的名字。这一页只定义命名本身；机制归属各自的系统文档。

## 结论

**名字就是地址。** actor 只有两条 actor-facing 寻址方式：

- 当前称呼（例如 `父亲`）：来自该观察者对那个签名的名字表；
- 签名编号 `#12`：还没认出它，或者这个称呼分不开时用。

真名不是特权地址：观察者叫它「父亲」，地址就是「父亲」；真名只在观察者当前称呼正好等于它时才成立。

## 术语

| 术语 | 指什么 | 出现在哪里 |
| --- | --- | --- |
| **名字** | 实体在控制面的展示名，例如 `角色甲`、`舞台一`、`道具一`。角色真名与舞台名在 world 内全局唯一 | 内容、API、日志、数据库、工具参数 |
| **签名称呼**（signature name） | 某个观察者当前给某个签名起的名字，可以是真名、称号、误认或听来的叫法 | `actor_signature_names` |
| **引用**（reference） | 由观察者视角拼出的地址：当前称呼，或 `#12`（没有名字 / 名字分不开）。未到访舞台也用 `#实体序号`；编号不得说出口，称呼本身是可以说的话 | 工具参数、名单、观察、行动反馈 |
| **签名**（signature） | 一个 actor 可被看见的一种形态：`form` 是稳定描述。同一 actor 可以有多条签名，当前只有一条生效；换签名即改变可辨识性 | `actor_signatures` |
| **外观**（appearance） | 某个签名的一次渲染记录：`text` 是最终可见文本，`input` 保存生成时的完整输入。append-only，当前记录由 `superseded_at is null` 标记 | `appearances` |
| **形态**（form） | 签名上的稳定描述，统一写成 `种族:描述`；描述里包含能锁定身份的标记部位，换装不改写它 | `actor_signatures.form` |
| **内容键**（content key） | 内容层引用实体的稳定标识，例如 `actor-key`；避免用展示名当引用 | `Actor.key` |

## 名字作为地址

- **名字是观察者的认知**：同一个角色在不同观察者眼里可能是「角色甲」、「守墓人」或 `#12`；actor-facing 检索只走签名或观察者当前名字，id 只是存储身份。
- **真名不是特权**：认得一个签名不等于知道真名。观察者叫他“父亲”，地址就是「父亲」；真名“甲”只在当前名字正好是它时成立。
- **只有一个当前名字**：同一个 observer × signature 只保留一个当前值。需要改称呼就覆盖，不维护同时可用的别名集合。
- **重名是合法认知**：两个人都被叫「父亲」，是观察者真实的状态（统称、误认、看不清）。名字不能当地址时退回编号，名字仍作为标签留在展示里；引擎不在写入时阻止重名，也不逼角色编造 `父亲01` 这种它感知不到的区分。
- **编号不是名字**：`#12` 只是「这个名字现在不能当地址」的占位；它不是知识，也不该被记住当成名字。

## 两个面

- **世界面**：agent 看到的一切。引用与外观都按观察者渲染，外观不内联进句子；stage / world 写出的世界面文本受统一守卫，actor 读取时再按观察者渲染。
- **控制面**：客户端、CLI、故事整理器看到的完整状态。公共事件流与实体状态保留真名与稳定 id，不写引用标记。

客户端对 actor 的寻址接受真名与编号两种写法；移动目标仍用观看者投影里的 `stage.exits[].stageId`，出口同时带展示名与 `#实体序号`，客户端可自行遮蔽未访问舞台的名字。客户端要按角色视角展示时，用观看者投影读取该角色的记忆与引用，而不是重新渲染公共事件流。

## 适用范围

- **角色与舞台**：真名全局唯一，只在控制面使用；actor-facing 只认观察者当前名字或签名编号。舞台名是控制面的地点标签；NPC 到访后才知道名字，没走过的相邻舞台只给 `#实体序号`；去过、但此刻封着的出口写成「记得封着」的真名，只有到访过的人看得到。
- **道具**：名字是公共标签，按持有者 / 舞台唯一，允许跨作用域同名；直接写名字，没有「认不认识」这一层，所以也不会用到编号。
- **世界与世界职能**：没有可被称呼的名字，只存在于控制面（例如「世界一」）。

## 现状边界

- **签名切换只有数据原语**：`insertSignature` / `switchCurrentSignature` 与「名字按签名存」已经就位并有测试，但还没有游戏内的伪装 / 变身入口。
- **名字获取靠扮演层自律**：引擎只拦 `#编号` 与空名字；名字是否来自真实认知，由提示词与对话约束，不做真名校验。
