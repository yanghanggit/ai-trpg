# 术语表：名字与引用

同一个实体在不同观察者眼里可能被叫作不同的名字。这一页只定义命名本身——名字是什么、地址怎么拼；机制归各自的系统文档。

## 结论

**名字就是地址。** actor-facing 的地址只有两种：观察者当前给那个签名的称呼，或占位编号 `#12`。id 只是存储身份，真名不因此获得特权——叫它「父亲」，地址就是「父亲」。

## 术语

| 术语 | 指什么 |
| --- | --- |
| **名字** | 实体在控制面的展示名，例如 `角色甲`、`舞台一`、`道具一` |
| **签名称呼**（signature name） | 某个观察者当前给某个签名起的名字，可以是真名、称号、误认或听来的叫法 |
| **引用**（reference） | 由观察者视角拼出的地址：当前称呼，或 `#12`。编号不得说出口，称呼本身是可以说的话 |
| **签名**（signature） | 一个 actor 可被看见的一种形态；同一 actor 可以有多条签名，当前只有一条生效 |
| **形态**（form） | 签名上的稳定描述，包含能锁定身份的标记部位；换装不改写它 |
| **外观**（appearance） | 某个签名的一次渲染记录，append-only，只有一条当前记录生效 |
| **内容键**（content key） | 内容层引用实体的稳定标识；避免用展示名当引用 |

## 名字作为地址

- **名字是观察者的认知**：同一个角色在不同观察者眼里可能是「角色甲」、「守墓人」或 `#12`；actor-facing 检索只走签名与观察者当前名字。
- **只有一个当前名字**：同一个 observer × signature 只保留一个当前值；改称呼就覆盖，不维护别名集合。
- **不能当地址时退回编号**：重名（两个人都被叫「父亲」）是合法认知，引擎不阻止，也不逼角色编造 `父亲01`；`#12` 只是占位，不是知识，也不该被记住。

## 名字的作用域

- **角色与舞台**：角色真名与舞台名在 world 内全局唯一，只在控制面使用；舞台名是控制面的地点标签，没走过的相邻舞台只给编号。
- **道具**：名字是公共标签，按持有者 / 舞台唯一，允许跨作用域同名；没有「认不认识」这一层。
- **世界与世界职能**：没有可被称呼的名字，只存在于控制面。

客户端按角色视角展示时读观看者投影，不重新渲染公共事件流。

## 现状边界

- **签名切换只有数据原语**：有类型与存储，没有游戏内的伪装 / 变身入口。
- **名字获取靠扮演层自律**：引擎只拦 `#编号` 与空名字，不做真名校验。
