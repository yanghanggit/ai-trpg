# 术语表：名字与引用

同一个实体在不同观察者眼里可能被叫作不同的名字。这一页只定义命名本身；机制归属各自的系统文档。

## 结论

**名字是认知，引用是地址。** actor 只有两条 actor-facing 寻址方式：

- 签名编号 `#12`：不需要先知道任何名字；
- 当前名字 `@名字`：来自该观察者对那个签名的名字表。

真名不是特权地址。只有观察者当前给签名起的名字正好等于真名时，`@真名` 才成立。

## 术语

| 术语 | 指什么 | 出现在哪里 |
| --- | --- | --- |
| **名字** | 实体在控制面的展示名，例如 `奥德里克`、`墓园`、`松脂火把`。角色真名与场景名在 world 内全局唯一 | 内容、API、日志、数据库、工具参数 |
| **签名称呼**（signature name） | 某个观察者当前给某个签名起的名字，可以是真名、称号、误认或听来的叫法 | `actor_signature_names` |
| **引用**（reference） | 由观察者视角拼出的地址：`@名字`（当前有名字）或 `#12`（还没有名字）。只能用在系统写给角色的文本与工具参数里，不得说出口 | 工具参数、名单、观察、行动反馈 |
| **签名**（signature） | 一个 actor 可被看见的一种形态：`form` 是稳定描述。同一 actor 可以有多条签名，当前只有一条生效；换签名即改变可辨识性 | `actor_signatures` |
| **外观**（appearance） | 某个签名的一次渲染记录：`text` 是最终可见文本，`input` 保存生成时的完整输入。append-only，当前记录由 `superseded_at is null` 标记 | `appearances` |
| **形态**（form） | 签名上的稳定描述，统一写成 `[种族]:描述`；描述里包含能锁定身份的标记部位，换装不改写它 | `actor_signatures.form` |
| **内容键**（content key） | 内容层引用实体的稳定标识，例如 `odric`；避免用展示名当引用 | `Actor.key` |

## 为什么分开

- **名字不是地址**：同一个角色在不同观察者眼里可能是 `@奥德里克`、`@守墓人` 或 `#12`；actor-facing 检索只走签名或观察者当前名字，id 只是存储身份。
- **真名不是特权**：认得一个签名不等于知道真名。观察者叫他“父亲”，`@父亲` 就成立；真名“奥德里克”只在当前名字正好是它时成立。
- **只有一个当前名字**：同一个 observer × signature 只保留一个当前值。需要改称呼就覆盖，不维护同时可用的别名集合。
- **引用不是名字**：`#12` 只是「你还没有给他名字」的编号；它不是知识，也不该被记住当成名字。

## 两个面

- **世界面**：agent 看到的一切。引用与外观都按观察者渲染，外观不内联进句子；stage / world 写出的世界面文本受统一守卫，actor 读取时再按观察者渲染。
- **控制面**：客户端、CLI、故事整理器看到的完整状态。公共事件流与实体状态保留真名与稳定 id，不写引用标记。

客户端对 actor 的寻址接受真名与引用两种写法；移动目标仍用观看者投影里的 `scene.exits[].stageId`，出口的展示名只用于显示。客户端要按角色视角展示时，用观看者投影读取该角色的记忆与引用，而不是重新渲染公共事件流。

## 适用范围

- **角色与场景**：真名全局唯一，只在控制面使用；actor-facing 只认观察者当前名字或签名编号。场景名是地点标签（公开）。
- **道具**：名字是公共标签，按持有者 / 场景唯一，允许跨作用域同名；只写纯名字，不用 `@`。
- **世界**：没有可被称呼的名字，只存在于控制面（例如「枯钟修道院的故事」）。

## 现状边界

- **签名切换只有数据原语**：`insertSignature` / `switchCurrentSignature` 与「名字按签名存」已经就位并有测试，但还没有游戏内的伪装 / 变身入口。
- **名字获取靠扮演层自律**：引擎只拦系统层标记（`@` 与 `#编号`）与空名字；名字是否来自真实认知，由提示词与对话约束，不做真名校验。
