# 术语表：名字与指代

同一个实体在不同平面上有不同名字。这一页只定义命名本身；机制归属各自的系统文档。

## 结论

**名字是知识，指代是地址。** 系统用规范名寻址，角色只知道自己被世界告知过的称呼；两者混用会同时破坏路由与认知隔离。

## 术语

| 术语 | 指什么 | 出现在哪里 |
| --- | --- | --- |
| **规范名**（canonical name） | 层级名 `类别.名称`，例如 `角色.奥德里克`。系统的全名，用于路由、内容引用、日志与调试，不是世界内的称呼 | 内容、API、日志、工具参数之外的系统层 |
| **本名**（true name） | 规范名的末段，例如 `奥德里克`。实体在世界内本人使用的名字，只能经介绍、听闻或发现获得 | `actors.name` 的语义；名字信念的内容 |
| **称呼**（known-as） | 某个观察者相信对方叫什么。可以是假名、误称、身份代称，也可以改口；不要求等于本名 | `name_knowledge` |
| **指代**（handle） | 观察者相对的 `@<形象序号>`。稳定、不透明、不含本名；可以用于指定对象，不得说出口 | 工具参数、同场景名单、行动反馈 |
| **形象**（presentation） | 一个 actor 可被看见的那具身体：稳定识别特征加当前外观。换形象即改变可辨识性 | `actor_presentations` |
| **内容键**（content key） | 内容层引用实体的稳定标识，例如 `odric`；避免用展示名当引用 | `Actor.key` |

“真名”一词留给将来可能出现的世界内机制（例如真名咒缚），不用于本名。

## 为什么分开

- **规范名不是知识**：把末段当姓名，等于让角色直接读到系统路由表。
- **称呼不是真名**：信念可以错、可以被骗。把称呼写成真名映射，就丢掉了误认与说谎的空间。
- **指代不是名字**：它是本轮寻址用的临时标签；名字按形象存，所以伪装后旧称呼不会跟到新形象上。

## 两个面

- **世界面**：agent 看到的一切。名单给 `@3 名字（此刻的样子）`，未知时只有外观；句子里的自然称呼用名字或外观。
- **控制面**：客户端、CLI、故事整理器看到的完整状态。公共事件流与实体状态保留规范名与稳定 id，客户端自行决定展示与隐藏。

客户端寻址接受稳定 id、规范名与指代三种写法，优先用 id；裸的本名不由服务端解析，由客户端在自己的状态里换算成 id。
