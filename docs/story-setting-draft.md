# 海门（Haimen）——游戏设定（草案 Draft）

## 一、城市

- **位置**：大江入海口，内河航道与远洋航线唯一的交点。船从海上进，货从江上出。
- **结构**：城沿旧码头层层加建，越往下越老；最底层是墓。
- **文化基调**：东方形制为主，掺外洋器物。

## 二、封闭的原因

- **局势**：天灾是黑疠；人祸是军阀混战与贵族、官员的衰败。
- **疫病**：两年前，沿海港口相继封港，黑疠随船进入海门——一种只能压、不能治的瘟疫。海门是唯一还在卸货的港口；城里缺药，人口持续减少。
- **入侵**：一年前，公爵率血族从海上打进来，占了海门。公爵、管血者、主教出自西陆，棘卫长出自东洋。四人各占一区：港口与税关、铸币街、经院、船坞营垒。区里自成规矩：官署的人进不去，血族不受官署审判。其余四类人都是本地人：贵族与官员、旧教团、码头中间人、抵抗者。
- **妥协**：血族进城时，贵族与官员带兵打过，被打服，兵也打没了；旧教团留在老城，不掌权。他们与血族签下血契：官署替血族征血、上血册，血族给配额药。
- **血疗**：用血治黑疠；进城者先做一次，做过就上血册。
- **血册**：上血册的人领药、交血；不上册的人没有药，也出不了城。
- **药**：只压黑疠，停药复发。
- **镇压**：反抗者由血族清除，或被贵族与官员以「治安」名义交出去。
- **人祸**：城名义上由旧贵族与官员治理，官署、警察与税收照常运转，替血族征血。
- **封城**：只进不出。船可以进，货可以出，人不能出；出港船必须卸空，由血族押运。进城者先过血疗、上血册。白天官署与警察管老城，入夜血族的巡逻队可以走全城。
- **城外**：几支军阀互相牵制，打不进来，也接管不了海门。
- **目的**：公爵要城下古墓里的旧血，因为主教说旧血能续命；主教要的是教义里的秘密。

## 三、血与四位统治者

**血族**：

- 强处：刀枪不入，寻常刀剑与子弹伤不了。
- 弱点：日光；寿命，三五百年到头。
- 喝血：只是饥饿。血族控城是为了有稳定的血，跟畜牧一样：养着，定期取。
- 转化：除第一个血族，其余都由别的血族转化；链子就是控制权，捏在转化者手里。转化出来的人怕日光。

**血族的供养**：

- **血税**：上血册的人定期交血，供血族自己吃。
- **转化兵**：血族咬人，转化成兵，再从兵身上抽血炼药；兵取多了会弱，就再转化一批。
- **卖药**：药卖给没被转化的人压黑疠，换钱。

**药**：血族从转化的兵身上取血炼成，发药是控制百姓的手段。炼过就失去转化之力，只压病、拖老，不造同类。血族不染疫；人血因疫病变薄，须炼制才能入口。药有两个去处：人的黑疠、血族的老，两边都不够。

**旧血**：

- 本质：古老者的血，也就是血族的血，比一般血族之血更强。
- 作用：转化；转化者不怕日光；吸收——喝干一个血族，得到他的记忆、能力与剩下的天数。血族喝血只续命，不吸收。三样城里无人知道；吸收尤其不进游戏文本，靠玩家在游玩中撞见。
- 掺水：只改一半，撑到三十天开始排斥，排斥到底人就没了。这个期限只落在被掺水旧血改过的人身上。
- 知情：知道它是什么的只有三方——主教（教义）、公爵（主教告知）、旧教团（旧典）。

### 血契公爵（男 · 主）

- 西陆来的血族，海外新兴血族势力里最强的一个；已快到尽头。
- 据点：旧税关塔楼。
- 行事：不亲自动手，只定血契与血税。
- 目标：港口、税关与商路；以及主教说的那座古墓，旧血能续命。
- 药：不放自己的血，全从转化的兵身上取；对外说成恩典。

### 管血者（男 · 辅）

- 西陆贵族，被公爵转化。公爵许诺战后让他管土地与税赋，他当真了。
- 据点：旧铸币街，银库改血库；人血炼食粮，兵血炼药。
- 职权：街区的规费、巡夜与血疗。
- 配药：官署定额只给最稀的一档；黑市另算，最好的留给出价最高的人。
- 动机：贪；怕公爵查账；疑心公爵另有目的，不敢问。

### 棘卫长（女 · 辅）

- 东洋贵族。公爵在东洋击溃她的忍者，把她与残部一并转化，又把忍者的链子交回她手上；她只服强者，对公爵最忠。
- 据点：旧船坞营垒。
- 职权：名单、夜里的失踪、码头上的尸体。
- 伏笔：封门那夜她的人守在门后。
- 关系：看不起管血者与主教。

### 秘仪主教（男 · 辅）

- 比公爵更老的血族。他没来过海门，古墓与古老者的事是从教义里知道的。
- 他跟公爵回来，要弄清教义里的秘密。他对公爵说旧血能续命，公爵才带兵来挖。
- 手段：改写人——先改语言，再改名字。
- 目标：挖开那座墓；旧教团必须消失，本地信仰换成他的教廷。
- 位置：不争主位；公爵要挖墓，得留着他。

**军力对照**：

- 公爵：唯一的正规军团，兵都是他转化的，编成粗陋。
- 棘卫长：忍者与船坞驻屯队，名义归公爵，实际只听她。
- 管血者：血库守卫、铸币街巡夜。
- 主教：执事、少量护教守卫。
- 贵族与官员：兵已打光，只剩警察与家丁。
- 秩序：四区规矩由各自守卫维持，压不住时公爵的军团兜底。老城警察不进血族区，血族不收编警察。

## 四、本地势力

- **旧教团**：没有名分也没有兵，只剩旧籍、旧契与法器。旧典记着墓下的古老者；旧契记着封条。不争教权，只想知道古老者留下了什么。
- **贵族与官员**：有名分，兵已打光。官署、警察与税收在旧城运转；港口、税关与四个血族区管不了。
- **码头中间人**：做码头、暗巷与渡口的生意：偷渡进城、抹掉血册上的名字、给肯出钱的血族弄额外的血、卖假药、卖出城的死路。不问立场只收钱；城里少了谁，他们最先知道。
- **抵抗者**：各街区凑起来的人，目标：推翻血族。血族杀不死，他们只能烧血库、杀替血族办事的人；截下的药当场烧掉，自己不领。入伙的多半没了家人；不信旧教团，也不信贵族与官员。

## 五、城下的墓

- **位置**：城的最底层；比城与血族都老。
- **古老者**：海路开通前守这片江口的血族先民。他们散成血，壳留在原处：血封住底下的东西，壳把它钉住。
- **起源**：血族的第一口血来自这座墓；有人把它带出海门，才有后来的血族。
- **封条下**：压着一个比血族更老的东西，从海里来；江口是它唯一能上岸的地方，古老者用自己封住它。
- **旧血**：墓里唯一还会动的东西；不认血族，也不认人。每被取走一滴，封条薄一分。
- **记住**：谁碰旧血，它就记住谁。被记住的人散的时候化回旧血，封条借他的形把一部分自己带上来。
- **日光**：旧血不怕日光，这是封条下那东西的性质；血族怕光，因为他们是稀释过的后代。
- **旧契**：旧教团手里的旧契是封条的记录，不是地契。他们不说：说了没人信，也等于承认封条已经松了。
- **主教的秘密**：教义说古老者留下了「更高的血」，喝下去就能得到他们的记忆与能力。他以为那是升格；那血是封条。
- **危险**：塌方、机关与旧血；挖进去的人十个回来三个。
- **入口**：公爵的塔楼正对墓口。

## 六、主角：外乡人

- **身份**：外乡人，为黑疠来海门求药；没有门路，没有熟人。
- **起点**：花钱让码头中间人把他偷渡进城，在码头上挨了一针，针里是掺了水的旧血。施针的人此后再没出现。
- **现状**：旧血改了他一半。他不上血册，没有链子，不染黑疠，也不怕白天；不怕白天这件事，是他自己发现的。
- **期限**：不纯的旧血在排斥，三十天到顶人就没了。只有他一个人有这个期限。越接近越压不住：眼红、体温骤降、瞳孔变形，夜里听得见旧血在响，也开始渴血。
- **能力**：喝干一个血族，他拿到对方的记忆、能力，以及对方剩下的天数。
- **两难**：公爵与主教都要他的血，那是唯一活着的旧血样本；人见了他的样子会报官。续命只有一条路，就是继续喝；接受转化能活，但要交出白天。城里也许还有别的办法，他找不到。
- **核心冲突**：三十天是第一条命；往后每多一天，都要从一个血族身上拿。
