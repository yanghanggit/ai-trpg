# 信息披露：actor / stage / world / item

四个实体的分界：**名字与稳定 id 属于控制面；actor 看到的世界面只出现能被感知的引用、外观与事实**。全知的范围各不相同，但都不等于可以下推。

## 全知的边界

“全知”只描述**世界状态**：

- **world** 全知全部场景：全部场景的 profile、environment、陈列物品，以及全部 actor 的名字与所在场景；不读 actor 的 profile、开局简报与记忆，也不看 actor 外观与背包。它的 profile 与收尾条件只属于控制面，actor 与 stage 只拿到战役设定与全局规则。
- **stage** 只全知本场景：自己的 profile、environment、锚点及其上的物品、未开启通道、本场景事件，以及在场 actor 的名字、外观与携带物；它没有跨场景查看入口，其他场景的信息只能经 world 中转。
- **actor** 只知道自己的设定与记忆，以及当前场景的 environment、陈列物品与在场角色；NPC 任务提示词里，没走过的相邻场景只以 `#实体序号` 出现，到访记入 `stage_visits`，可以用 `get_visited_stages` 回看；**去过、但此刻封着的出口对它列成「记得封着」**（认得名字，走不过去），没走过的门连名字都不知道；他者的完整背包不在名单里（名单只有已穿戴的槽位）：要看全得花一次 `inspect` 动作，清单只回给查看者，留不留痕迹看敏捷。
- **item** 的名字、大类与描述是公共标签，不做 actor 级隔离；它在哪里、在谁身上仍由观察范围决定。

两条推论：

- **全知不等于可以下推**：受守卫的是 actor 能读到的文本（environment、观察与行动反馈）；裁决、报告与结局文案都不进 actor 的上下文，因此不拦名字。事实与机制的保密仍靠提示词与内容分层。
- **认知隔离只属于 actor**：签名称呼、引用与外观回答的是「这个角色当前怎么称呼谁」；stage / world / item 用名字与公共标签，没有观察者相对的名字表。

推理端的仲裁 agent（如词缀）不属于四个实体：没有记忆与观察者视角，只做一次增量判定。

## 下行披露

| 通道 | 允许 | 禁止 |
| --- | --- | --- |
| actor → actor | 当前称呼或外观交谈、转述 | `#编号` |
| stage → actor | environment、观察与行动反馈，按观察者渲染 | 角色真名（作为叙述对象）、还没打通的通道对面的场景名 |
| world → stage | 世界裁决、跨场景变化，写进 stage memory | —（stage 对名字全知） |
| world → player | 结局文案，只写 `game_messages` | —（不进任何 agent 的记忆与上下文） |
| stage → world | 场景报告，可含名字 | 不构成对 actor 的下推 |
| 引擎 → world | 引擎确认的事实（主角死亡），写进 world memory | 不替 world 写结局，也不结束整局 |
| stage ↔ stage | 无事件/记忆通道 | — |

世界面文本在写入时统一守卫，actor 读取 environment 时再按观察者渲染一次；控制面保留真名与稳定 id。玩家台词进入 actor→actor 通道前先过玩家对话审核。

→ 参见：[名字审计](name-audit.md)、[玩家对话审核](dialogue-audit.md)、[Actor 行动与记忆](actor-actions-memory.md)

## actor 与场景

actor 只感知当前场景；普通移动的**可达**只认当前场景的开放相邻边。`teleport` 是例外：目标真名能解析到场景就能直接传送，不看路径，也不查知识账。记忆、公共知识检索与他人转述不授予普通移动通行权。

路线回忆回答的是一条链，不是「能不能到」：能走通就写出整条路线，走不通把链拉到断点、在断处标 `→[封着]→`，门后接不回终点时以 `…` 收尾；确实没有连接时才说没有路。

端点只要求是能解析到场景的真名，`#实体序号` 不能用来问路：编号只表示「看得见但还没命名的站位」。端点不要求在 `stage_visits` 里——问路是推理，不是位移。链上的渲染按走到过哪里算：没走过的位置（包括没走过的端点）写成 `#实体序号`，与「看得见的出口」是同一种写法，标题仍回述问题里的名字。地名对不上任何场景时，这次回忆记为「无法寻路」并写进自己的记忆。

→ 参见：[传送](teleport.md)、[公共知识检索](rag.md)、[架构与契约](architecture.md)

## 仍未结构化

- **事实与机制**：stage / world 知道钥匙与锁孔吻合、通道是唯一出口，引擎只拦得住「未通场景的名字」，拦不住它们用别的话把未发现的事实写进可见文本。
- **隐藏通道与秘密地点**：通行性没有 per-actor 版本——通道只分 `open` / `sealed`，一旦打开对所有人可见；actor 级差异只有「记忆」这一层（去过的地方即使封着也认得出名字）。发现入口本身仍是内容裁决，不建状态。
- **地名知识只有到访一条来源**：台词、公共知识检索与他人转述都不写状态；`stage_visits` 是唯一账本。因此「模型说得出某个地名」在引擎看来什么都不是——问路与传送都只按名字解析，不按认知放行。
