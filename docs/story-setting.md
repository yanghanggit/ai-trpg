# 故事设定草案

当前剧本的核心设定，够开局与跑通即可。古遗迹的真相、星空与深渊的宇宙论、其他不死族军团一律留白，需要时在对应实体上就地扩写。

## 世界与城

瘟疫（烈度近黑死病）随不死族兴起，世界秩序崩坏。不死族不止一支，远征者只是其中一支，洛恩只是远征途中的一站。

洛恩是海陆枢纽，一面环海，一面接陆。地层即历史，自上而下叠了四代：

| 层 | 要点 |
| --- | --- |
| 无名古文明 | 不设名，只留遗迹、深海意象与禁忌 |
| 先民 | 信深渊，建城，发现古遗迹与白银 |
| 贵族 | 推翻先民，以商业立城，反旧教；战败后残部成旧贵族 |
| 远征者 | 征服者，见下 |

地下依次是：贵族城区与先民遗构 → 先民旧信仰遗存 → 古遗迹 → 白银矿藏。两条暗线在同一处重叠：**白银**归船长，**深渊**归主教。

地界也大致对应三面：码头是黑帮与外乡人的地界，上层是旧贵族与总督的地界，地下是矿工、旧教与遗迹的地界。

## 不死族

- 靠血税维生，白天不能行动。
- 银能致死：银刃致命，银币只灼痛。因此不亲手碰银，矿区与银的流通全经人类之手。
- 只有船长、主教、忍者能转化。转化是故意咬噬并消耗自身体力的行为。
- 眷属强于常人、能白天行动、外形畸形；血可再生，被长期采血供药。
- 人数稀少，必须留活人交血挖矿，所以不屠城，只能借本地势力统治。

## 占领者

| 角色 | 一句话 |
| --- | --- |
| 船长 | 首领与最高武力，要银矿锻兵器、以血税奴役百姓 |
| 主教 | 比船长更古老，表面信星空，暗中找深渊与先民线索，瞒着船长 |
| 忍者 | 船长特务，来自上一个征服地，嗜杀，只忠于船长 |
| 总督 | 船长眷属，本地投诚的三流贵族，名义「贵族首领」，白昼代理人 |

信息隔离就是剧情资源：船长只要银与血，主教独占深渊，忍者不知主教的秘密，总督只经手白昼事务。任意两人之间都有可撬的缝。

## 制度

- **封城**：常制。断人口与疫病，保开矿、贸易与血税。
- **血税与劳役**：定期交血，轮班下矿。
- **解药**：主教以眷属之血制作，产量够全城，配给权在远征者。暴力、疫病、药依赖三重束缚。

## 本地势力

| 势力 | 诉求与处境 |
| --- | --- |
| 旧教 | 先民遗存，信深渊，藏于暗处，守遗迹禁忌；最怕主教与忍者 |
| 旧贵族 | 保财富与残存权力，有私兵；被总督统辖，暗通黑帮或旧教 |
| 黑帮 | 在配给与血税里抽成、倒卖；不直接对抗远征者，是唯一横跨三方的中间层 |
| 平民 | 求活命、少交血、拿到药；分裂为顺从、求生、抵抗三类 |

## 外乡人

来自海外东方国度的普通人，非不死族、非眷属、非贵族。他已染瘟疫，寿命只剩有限天数，唯一线索是「洛恩有瘟疫疗法」，但他不知道药出自眷属之血。

他无籍在册，随时可能被盘查、驱逐、扣押或当作逃疫者处理；能走的路只有信息与关系，不是武力。开场前他遭遇海难，被冲到码头破落区，昏迷中记得被‘深渊之民’救起，真相未明。

他的张力在两处：要找的药正是统治工具本身；无籍既是他在洛恩唯一的活动空隙，也意味着没有任何一方会为他负责。
