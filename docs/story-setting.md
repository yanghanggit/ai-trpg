# 海门（Haimen）——游戏设定

## 一、城市

**海门**，大江入海口的江海交汇之城。江水从西边来，海在东边，海门卡在中间，是内陆水道与远洋航线的唯一交点。船从海上进来，货从江上下去，人从四面八方来，在这里换船、换钱、换身份。城市的底层是旧码头的地基，一层叠一层，每一层都比上一层更老。**最底下那一层，没人说得清是什么。**

**文化基调**：东方元素以符号和美学进入——旧式飞檐压在西式石砌立面上，江边的塔楼挂着外洋运来的玻璃灯，本地话里夹着听不懂的海外词。旧管理机构叫“行会”，地下势力叫“码头盟”。

## 二、封闭的原因

海门没有被迷雾笼罩，也没有被城墙围死。它**仍然通航**，但三条线同时收紧：

1. **瘟疫**：城外的疫病没有消退，沿海港口一个接一个封港。海门是少数还在运转的港口，但任何离港的船都要经过检疫，检疫印章掌握在血族手里。没有印章的船，出了海门也没有港口让你靠岸。
2. **配给凭证**：圣血配给凭证同时是健康证明和通行证明。没有凭证的人可以留在城里，但**上不了船，过不了关卡，出不了城门**。不是城墙挡住了人，是**纸挡住了人**。
3. **远方的战争**：都城的内战没有结束，沿海航线被各方势力切成碎片。即使出了海门，下一座港口可能正在打仗，再下一座可能已经封了。

## 三、四位血族Boss（海外来的统治者）

### 血契公爵（男）——西陆来的古老血族，帝国逻辑本身

来自大洋另一侧的西陆。夺取海门，是因为这里有现成的港口、税关和商路，**还有码头底下的东西**。据点设在旧海关塔楼，塔顶挂一面用血染过的旗。不亲自动手，设计规则：血契、配给、封锁、焚城令。唯一在意的，是血税稳定和**码头底下的挖掘进度**。

### 管血者（男）——西陆商业逻辑的血族

掌管圣血的采集、炼制与配给。占了旧钱庄街，把银库改成血库。账本用复式记账，每一滴血都有编号和“损耗率”。需要所有人怕他，因为他**怕自己不够被怕**。怀疑公爵来海门不只是为了血税，但不敢问。

### 棘卫长（女）——东洋来的血族，公爵的刀，彻底臣服

东洋岛国出身。公爵在东洋打败了她，她从此臣服——不是被迫，是**被打服了**。东洋人崇拜强者，谁打赢了他们，他们就跟谁走，跟得比谁都忠诚。她穿层叠暗红甲胄，腰间佩刀，兵营设在旧水师营，棘卫操练口令是东洋话。公爵说烧城，她就标油料；公爵说封门，她就挂人。不问为什么，问为什么就是对强者的不敬。她看不起管血者的算计，也看不起秘仪主教的绕弯子。海门人看她，看到的是一个东洋人替西洋血族管着城门——她站在城门下，本身就是一道“你不是这里的人”的界碑。**她的裂缝**：忠诚建立在“公爵是最强的”这个前提上。如果有人**在正面交锋中**证明公爵不是最强的，她的忠诚会瞬间转向。不是背叛，是追随更强的那个。

### 秘仪主教（男）——西陆更古老的存在

比公爵活得更久。公爵知道，公爵不舒服。掌管同化院和“终版圣血”研发。同化院在旧书院里，走廊挂满“毕业生”画像，每一张脸都很像。不折磨肉体，**改写人**。对码头底下的东西的兴趣，可能超过对血税的兴趣。他来海门，也许和公爵找的不是同一样东西。

## 四、本地势力

**旧档司**：前朝档案保管者，藏在码头下废弃货栈。手上有地籍册、旧契约、隔离古法。不谋求复辟，只想知道**码头底下埋的是谁**——那个转化了主角的血族，也许不是无名之辈。

**请愿者**：诉求不是推翻血族，是**公开配给名单**。领袖是前文书吏，妻子死于配给延迟。管被划掉的名字叫“**冤册**”，在配给站门口念。

**保长们**：街区中间人，管血者的名册通过他们落地。他们**挪名**——改代码、换顺序——每救一个人，就可能意味着另一个街区有人被划掉。

**渡盟**：码头下的暗道网络，头目**渡婆**。卖假凭证、私血、出城路线。她见过码头底下的东西，**她不说**。账本上记着每一个“渡”出去的人，大多数名字旁边没有圈。

**新政府联络官**：都城任命的委任官，办公室在城外旧驿站，连城门都进不去。每年写报告回都城，不提血族，只提“疫病严重，暂由地方维持”。都城的当权者身边有一位妻子，**她本身也是血族**，来自海外，和公爵不是同一批，但彼此知道。她说：“让他们待着，有用。”

## 五、主角：码头底下爬出来的血族

主角是**本地被转化的血族**。转化他的血族埋在海门旧码头地基下面，比海外血族早得多。那个血族转化主角后不久就“散”了，原因不明。**主角的来历无从可查**——旧档司的铁册里也许有一笔，也许没有。

**核心倒计时：30天不吸血，就会死。**

主角的转化用的是**本地土生的不稳定血脉**，不是公爵的标准圣血。30天不吸新鲜的血，排斥到临界点，主角会散。

**但吸血意味着暴露**：吸血后几小时内，血族特征会显现——眼红、体温骤降、瞳孔变形。在海门，这同时触发两边的追杀：

- **Boss阵营**认出你“不是我们的人”（你的血和海外血族不一样）。
- **本地势力**认出你“是吸血鬼”（管你哪来的）。

**核心冲突**：**不吸血会死，吸血会被两边同时看见。** 每多活一天，就多一天被发现的可能。主角必须在30天内找到一种**不需要暴露也能维持的办法**，或者接受暴露的代价。

## 六、关键暗流

| 暗流 | 内容 |
| --- | --- |
| **公爵 vs 秘仪主教** | 都在找码头底下的东西，但找的**可能不是同一样东西** |
| **棘卫长的忠诚前提** | 她臣服于公爵，因为公爵打赢了她。**如果有人证明公爵不是最强的**，她的忠诚会转向——但必须正面赢，不能靠诡计 |
| **管血者 vs 所有人** | 怀疑公爵和主教来海门另有目的，但不敢问。血税体系可能只是**掩护** |
| **渡婆的秘密** | 她见过码头底下。她不说。她知道的东西可能比旧档司的铁册更多 |
| **主角 vs 两边** | 不吸血会死，吸血会被两边同时认出。**两边都不属于他，两边都在找他** |

## 七、终局方向

**判定时点**：主角30天临界点。

**变量**：四Boss状态、主角的排斥是否解决、主角是否暴露。

- **弑主**：杀死四位Boss。海门权力真空。排斥可能解决，也可能没有。
- **入局**：加入某一Boss。有了靠山和血源，但成了本地势力眼中的叛徒，也成了其他Boss眼中的“那边的人”。
- **殒命**：排斥临界，或者**在吸血暴露的那一刻被两边同时扑上来**。
- **出奔**：找到出城的路。你走了，排斥带在身上，但海门之外还有没有能靠的港口，没人知道。
- **新主**：你坐上某个位置。**但你用什么血活下来，你就会变成什么样的统治者**。码头底下的东西如果被你挖出来，海门的下一章由它决定。
