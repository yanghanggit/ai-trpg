# 临时测试剧本：枯钟修道院

> 状态：临时内容，只服务当前行动、记忆、物品与通关链路的验证，不是最终剧情，也不是长期内容模板。

剧本在 `apps/server/seeds/dark-fantasy/bell-monastery.ts`（战役文本在同目录 `campaign.ts`），内容版本 `dark-fantasy.v13`，`contentKey` 为 `bell-monastery`。测试世界使用独立的小型 `TEST_WORLD`，不随本剧本变化。

## 背景

“黑疖病”扫过河谷：先死牲口，再死人，腋下与脖颈鼓起黑硬的疖子。修道院收留过病人，也烧过尸体；院长发现唱诗班一个接一个倒下后，封死北面铁闸门，带人从别的路离开。钟楼再没响过。

留下的是掘墓人奥德里克、他的狗与地窖鼠群。鼠王靠尸体活下来，身上的跳蚤、啃过的粮食、钻过的裹尸布都是瘟疫的一部分。玩家扮演的无名者被封进刻满符文的棺材，架在乱葬坑沿醒来——瘟疫死者从不用棺材下葬。

## 场景图

| 场景 | 角色 | 场景物品 | 用途 |
| --- | --- | --- | --- |
| `场景.墓园` | 奥德里克、煤渣、坏运气 | 无 | 中庭；钥匙、谈判、暴力、护主与报信 |
| `场景.棺材` | 无名者 | 无 | 玩家起点；符文暗示主角的特殊性 |
| `场景.地窖` | 鼠王 | 无 | 酒窖鼠巢、沉睡 Boss、致命威胁 |
| `场景.焚尸房` | 无 | `武器.松脂火把` | 火武器伤害 |
| `场景.铁闸门` | 无 | 无 | 被封死的北门；用钥匙后由 stage 打开通往山道的通道 |
| `场景.山道` | 无 | 无 | 修道院之外的出口；逃出后由 world 裁决结束 |

连接以墓园为枢纽，由三组双向边、一条单向出口与一条初始封闭的单向边组成。双向表示两个方向各有一条有向边；单向表示只有一个方向存在边；封闭表示边已存在但不能通过。

| 连接端点 | 方向 | 说明 |
| --- | --- | --- |
| 棺材 / 墓园 | 棺材 → 墓园 | 单向出口；离开后无法返回 |
| 墓园 / 地窖 | 双向 | 石阶向下；坏运气报信与鼠王搜索都经过墓园 |
| 墓园 / 焚尸房 | 双向 | 小屋后的焚尸房，与铁闸门互不连通 |
| 墓园 / 铁闸门 | 双向 | 墓园北侧岩壁 |
| 铁闸门 / 山道 | 铁闸门 → 山道（初始封闭） | 只能由铁闸门的小 GM 打开；没有反向边 |

从棺材到山道只有一条路径：棺材 → 墓园 → 铁闸门 →（开门）→ 山道。地窖与焚尸房都只能原路返回墓园；山道到达后无路可去。

默认玩家角色是无名者；他死亡时死亡阶段只通知 world，收尾由 world 回合决定。奥德里克持有 `物品.闸门钥匙`（贵重物品，不在穿戴槽）；坏运气是鼠王唯一不攻击的子嗣；鼠王的 openingBriefing 声明自己在地窖沉睡：本场景出现任何说话、攻击或非等待行为即苏醒，苏醒后追杀所有非鼠类活物，无目标时自行搜索修道院；HP 120、damage 60、block 100。焚尸房的 `武器.松脂火把` 是 `damage 8`、`block 0` 的武器，词缀为“火焰顺着毛根渗进去：对多毛类生物额外造成武器伤害的一百倍，毛越厚烧得越透”；名字、描述与词缀都不提“鼠”，命中由 affix agent 依据种族与外观判断。鼠王与坏运气带“厚毛皮 / 蓬松的灰毛”，煤渣是“短毛”，因此普通角色无法击穿鼠王，火把词缀会在 LLM 结算中放大伤害。

## 能力声明

能力逐条写在每个 actor 的 `actions` 里，没有共享默认值。所有场景必须声明 `submit_environment`（内容校验强制）；只有铁闸门额外声明 `open_passage`，只有山道额外声明 `notify_world`——走出修道院之后才向 world 报告。world 的 `actions` 是 `notify_stage` 与 `end_game`。

| 角色 | 活物 | 移动/说话 | 战斗 | 道具操作 | steal |
| --- | --- | --- | --- | --- | --- |
| 奥德里克 | 是 | ✅ | ✅ | ✅ | ❌ |
| 煤渣 | 动物 | ✅ | ✅ | ❌ | ❌ |
| 坏运气 | 动物 | ✅ | ❌ | ❌ | ❌ |
| 无名者 | 是 | ✅ | ✅ | ✅ | ✅ |
| 鼠王 | 动物 | ✅ | ✅ | ❌ | ❌ |

移动/说话包含 say、whisper、announce、move、wait；道具操作指 give、pickup、use。动物不操作道具，煤渣与鼠王会攻击，坏运气不会。

## 动物语言

语言边界只写在动物自己的 `profile` 里，由 LLM 在角色设定内执行，不进 `SYSTEM_RULES`：煤渣是不说人话的犬，对非同族只低吼、呜咽、磨牙或短促“汪汪”，遇同族犬才用清晰语言；坏运气与鼠王对非同族只发鼠叫，鼠类同族间可清楚说话；三者心里都能正常思考，`mind` 不受叫声限制。

## 剧情路径

谈判路线：玩家推开棺盖爬进墓园，与奥德里克沟通。铁闸门的钟形纹下刻着旧铭文“灰烬之下，旧钟无名”；有人对他说出这句，他会当成留下守钟的故人，下一轮 `give` 交出钥匙。玩家走到铁闸门、对锁孔使用钥匙：`use` 只写场景事件，由铁闸门的小 GM 调用 `open_passage` 打开山道；玩家移动到山道，山道的小 GM 向 world 报告“有人逃出”，由 world 裁决是否结束。

暴力路线：玩家攻击奥德里克，煤渣通过同场景战斗记忆在下一次 NPC 回合自主反击；坏运气看到冲突后跑回地窖报信。鼠王是否苏醒由 openingBriefing 与 LLM 判断，不通过系统状态移除。钥匙在奥德里克背包里、不在穿戴槽，因此活着时也能被偷；偷窃只写受害者与 stage 的记忆，旁观角色不知道。

Boss 路线：鼠王被本场景的非 `wait` 行为惊醒后追杀所有非鼠类活物，无目标时按场景图自行搜索；攻击力足以秒杀普通角色。普通攻击无法伤害鼠王；火武器需先装备到 `weapon` 槽，`attack` 才会用它结算。

## 测试矩阵

| 测试点 | 触发 | 期望 |
| --- | --- | --- |
| 初始世界 | `create --seed dark-fantasy` | 六场景；墓园三 actor、棺材/地窖各一 actor；焚尸房有场景物品；铁闸门与山道为空；玩家出生在棺材 |
| 通道封闭 | `player-move` 到山道 | 边存在但未开启，移动被拒；打开后才出现在可去场景 |
| 打开通道 | 铁闸门 stage 回合 | 依据钥匙事件调用 `open_passage`；边可通行，写 `passage_change` 与 stage 记忆，不写 world |
| 通道拒绝/幂等 | 无 `open_passage` 能力或无未开启边 | 整份计划被拒，场景图不变；对已开启的边再次提交也被拒 |
| 逃出后报告 | 山道 stage 回合 | 报告进入 world memory，world 据此裁决是否 `end_game` |
| 玩家移动 | `player-move` | 只能沿连接移动；事件写入公共消息与环境记忆 |
| 感知 | `observe_actor` | 只返回同场景角色携带的物品，不返回对方的角色属性与生命（物品级 damage / block 仍返回） |
| 攻击 | `player-attack` 或 NPC `attack` | 伤害为 `max(0, damage - block)`；死者不再进入 loop，但仍可被攻击（空转） |
| 默认玩家死亡 | 无名者 HP 归零 | 写 `game_completed`，`status=completed`，后续行动被拒 |
| 动物语言 | NPC 沟通动作 | 同族清晰沟通，对非同族只发本族叫声；`mind` 不受限 |
| 狗的反应 | 攻击奥德里克后推进煤渣 | 煤渣据战斗记忆与 profile 自主决定反击，不是硬触发器 |
| 坏运气报信 | 冲突后推进坏运气 | 移动到地窖并报信；是否要两轮由计划顺序与动作上限决定 |
| 沉睡唤醒 | 场景内说话、攻击或非 `wait` | 由鼠王 openingBriefing 与 LLM 判断，不做确定性断言 |
| 窃取/给予 | `steal` / 暗语触发 `give` | 窃取为 private；活人身上被穿戴的物品不可窃取，尸体不限；钥匙不在穿戴槽，活着也能偷；暗语通过 say 进入记忆，奥德里克自行选择 give |
| 拾取 | `pickup` | 场景物品移入背包并从场景消失 |
| 使用钥匙 | `use` + `targetDetail` | 只写场景事件，不改连通性、不通知 world；开门由铁闸门下一轮裁决 |
| 游戏结束 | world `end_game`（主角死亡只是通知 world） | 只有 world 收尾，写 `game_completed` 与它自己命名的 `outcome` |
| 普通攻击 Boss | `attack` | 鼠王 block 100，空手伤害为 0；火把词缀由 LLM 额外放大 |
| 鼠王攻击 | 苏醒后推进鼠王 | damage 60 秒杀普通角色；清场后由 LLM 自行搜索下一个场景 |
| stage 记忆/环境 | 私密沟通、移动、stage 回合 | 起点与终点 stage 都写 memory；environment 只描述当前可见状态，不含角色名或历史 |
| 场景物品同步 | 拾取后推进 stage | environment 不再出现该物品，也不写消失过程；拾取事件留在 stage memory |
| actor 探针 | `probe --actor` | 只依据 actor memory 回答，不注入 observation，不写状态 |
| stage 探针 | `probe --stage` | 只依据 stage memory 回答，不注入 environment 或物品 |

## 已用真实 provider 验证

- 玩家爬进墓园后，奥德里克先盘问来路，不直接动手；攻击他后煤渣下轮自主反击。
- 坏运气在冲突后移动到地窖报信；鼠王苏醒后自行搜索并秒杀非鼠类活物，从未攻击坏运气。
- 玩家活着时私密窃取奥德里克背包里的钥匙：受害者收到被窃记忆，旁观者没有。
- 玩家说出暗语后，奥德里克下一轮先回应再 `give` 钥匙。
- 玩家拾取火把、装备后攻击鼠王：fixed damage 为 0，affix LLM 依据“厚毛皮”判定命中，补充“基础 damage × 100”并击杀（实测 800）。
- v13 实测（奥德里克由玩家接管）：对锁孔使用钥匙后，铁闸门 stage 一轮内完成 `open_passage + submit_environment`，未通知 world；山道 stage 一轮内完成 `notify_world + submit_environment`；world 一轮内 `notify_stage ×2 + end_game` 收束，`status=completed`、`outcome=escaped`。
- 推动奥德里克、墓园、再推动奥德里克：environment 已更新，奥德里克下一次 plan 读到新环境，stage memory 保留事件。
- 拾取火把后推动焚尸房：environment 只描述当前空场景，不写消失过程或历史痕迹。
- 对焚尸房与无名者发起探针：分别依据 stage / actor memory 回答，两次都不写 memory 或游戏事件。

## 暂不验证

- 武器槽切换、耐久与消耗；`count` 尚未自动扣除；拾取后的堆叠与其他武器效果。
- 暗语的硬性服从、沉睡/苏醒的确定性行为；当前都靠 profile 与 LLM 判断，是软触发。
- 通用物品数量、堆叠、唯一实例与所有权历史。
- HTTP 业务接口与 Web 游戏界面。
